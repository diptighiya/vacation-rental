Notes

Issues #20 (view), #23 (remove) · Data: GET /api/host/listings
  1. 1Add listingOpens the listing form (/host/listings/new). The new listing is saved as Pending.
  2. 2Stat tilesCounted from the same list as the table: total, approved (live), pending review, and confirmed bookings this calendar month.
  3. 3TableShows only this host's listings. Click a header to sort. Photo, price and booking count are on every row (#20 AC). The title links to the public detail page.
  4. 4Status badgeApproved (solid), Pending (outline), Removed (dashed). A rejected or removed listing shows the admin's reason on hover.
  5. 5RemoveAsks for confirmation first (#23), then does a soft delete. The listing leaves search, but existing bookings stay and get flagged. Remove is disabled on removed rows.
  6. 6Analytics linkGoes to the host dashboard, which #31 requires to be linked from here.
