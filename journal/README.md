# Scrum journal

One file per member per week, under `sprint-<n>/`, named `<name>-week-<n>.md`. Each report
answers three questions:

1. **What did I work on?** Link the issues and commits.
2. **What will I work on next?**
3. **What is blocking me?**

The burndown sheet and the sprint backlog screenshots are linked from each sprint's folder.
